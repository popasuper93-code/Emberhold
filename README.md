# Emberhold

Оригинальная 3D survival-игра (Three.js). Остров, крафт, строительство, животные, день/ночь, рулетка скинов.

## Играть в браузере

Открой `www/index.html` в Chrome / Edge.

## Сборка APK (GitHub Actions)

1. Зайди в репозиторий → вкладка **Actions**
2. Выбери workflow **Build APK**
3. Нажми **Run workflow** → **Run workflow**
4. Дождись окончания (5–12 минут)
5. Внизу артефакт **emberhold-debug-apk** → скачай `app-debug.apk`
6. Установи на Android (разреши установку из неизвестных источников)

## Управление

**ПК:** WASD, мышь, Shift, Space, E, Tab, 1–6, ЛКМ  
**Мобильный:** джойстик + кнопки (landscape)

## Что реализовано

- Процедурный остров, вода, деревья, камни
- День/ночь автоматически
- Животные
- Крафт, инвентарь, хотбар
- Рулетка скинов
- Настройки (графика, FOV, чувствительность, звук)
- Мобильное управление
- Сохранение прогресса

Названия и ассеты полностью оригинальные.
